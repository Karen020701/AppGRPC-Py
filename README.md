# Basic GRPC Project in Python

This is a simple example of how to use the GRPC architecture in Python. In this example, a server is implemented that responds to requests from a client.

## Requirements

To run this project, you need to have Python installed on your system. Additionally, you need the following libraries:

*grpcio*
*grpcio-tools*

To install them, you can use the following command:

```bash
pip install grpcio grpcio-tools
```

## Clone the project
You can clone the project from the repository:
```bash
git clone https://github.com/Karen020701/AppGRPC-Py.git
```

## Server

To run the server you must use
```bash
python server.py
```

## Client

To run the client you must use
```bash
python client.py
```
